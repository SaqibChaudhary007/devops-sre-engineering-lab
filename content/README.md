# Content System

GitHub is the permanent technical knowledge base. Videos, posts and articles are distribution and teach-back layers.

## Content Principle

> Every topic gets a content opportunity, but every topic does not need the same format.

## Priorities

P1 Flagship, P2 Core, P3 Supporting, P4 Reference.

## Workflow

```text
Learn
→ Verify
→ Build
→ Teach
→ Publish
→ Repurpose
→ Review
```

Public content must use the same evidence standards as repository content.
