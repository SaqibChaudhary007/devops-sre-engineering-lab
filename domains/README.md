# Domains

Domains own the **canonical technical knowledge** in this platform.

Each domain follows the same design process:

1. Knowledge Tree
2. Objectives & Learning Outcomes
3. Learning Sequence & Prerequisites
4. Sources & Evidence
5. Labs / Build-Break-Fix / Troubleshooting
6. Production / Senior / SRE / Architect Scenarios
7. Interview Bank & Follow-Up Trees
8. Assessments & Mastery Criteria
9. Content Mapping
10. GitHub Architecture
11. Publish

## Current Domain

- [D00 — Engineering Foundations & DevOps Mental Models](00-engineering-foundations/README.md)

Future domains will use the same structure so learners do not need to relearn how the repository works.
