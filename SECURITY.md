# Security Policy

This is a public learning repository.

## Never Commit

- passwords
- API keys
- tokens
- certificates or private keys
- internal hostnames or private URLs
- customer-sensitive data
- proprietary source code
- confidential production metrics
- private architecture details

## Production Examples

Production experience must be anonymized and generalized. Use patterns, not customer-identifying details.

## Reporting

If you find an exposed secret or sensitive detail, report it privately to the repository owner rather than opening a public issue containing the sensitive value.
