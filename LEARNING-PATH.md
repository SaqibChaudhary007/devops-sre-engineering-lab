# Learning Path

## Recommended Entry Path

For a new learner:

```text
D00 Engineering Foundations
  ↓
D01 Linux
  ↓
D02 Networking
  ↓
D03 Git
  ↓
D04 Bash & Python Automation
  ↓
D05 Containers
  ↓
D06–D13 Kubernetes
  ↓
Cloud / IaC / CI-CD / GitOps
  ↓
Observability / SRE / Incidents
  ↓
Distributed Systems / Security
  ↓
System Design / Platform Engineering
  ↓
Performance / FinOps / AI
  ↓
Architecture / Leadership
```

## Learning Levels

- **L1 Foundation** — What is it?
- **L2 Engineer** — How does it fit together?
- **L3 Senior Engineer** — How can it fail and how do I investigate?
- **L4 SRE** — How do I operate it reliably?
- **L5 Architect** — What should we design and why?

## Practical Levels

- **P0** Theory only
- **P1** Observed
- **P2** Built
- **P3** Broke and recovered
- **P4** Blind troubleshooting
- **P5** Designed and improved

## Rule

Do not rush to tools. Learn the engineering problem first, then the technology that solves it.

Start with [Domain 00](domains/00-engineering-foundations/README.md).
