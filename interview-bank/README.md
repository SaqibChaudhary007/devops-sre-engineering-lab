# Interview Bank

Interview preparation tests understanding and reasoning, not memorization.

## Progression

```text
What?
→ Why?
→ How?
→ What fails?
→ How do you know?
→ How do you fix it?
→ How do you operate it reliably?
→ How would you design it differently?
→ What trade-off did you make?
```

## Levels

L1 Foundation, L2 Engineer, L3 Senior, L4 SRE, L5 Architect.

Reported interview questions must be clearly distinguished from practice questions created by this project.
