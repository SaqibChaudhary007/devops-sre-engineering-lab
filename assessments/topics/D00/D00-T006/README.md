# D00-T006 Assessment Package — Cloud Mental Models

This package evaluates whether the learner can reason about cloud operating models, control/data planes, elasticity, service models, shared responsibility, failure domains, quotas, governance, cost, and cloud-native architecture without depending on provider product memorization.

## Assessment Components

1. [Knowledge Check](knowledge-check.md)
2. [Applied Cloud Scenario](applied-scenario.md)
3. [Senior / SRE / Architect Follow-Ups](interview-followups.md)
4. [Teach-Back Assessment](teach-back.md)
5. [Rubric & Remediation Guide](rubric.md)

## Recommended Order

Knowledge Check
→ Applied Scenario
→ Follow-Ups
→ Teach-Back
→ Rubric Review

## Topic Competency Guidance

Recommended minimum:

- Knowledge Check: 80%
- Applied Scenario: 75%
- Follow-Up Depth: FD-3
- Reasoning Level: at least L3
- Teach-Back: 4/5 average
- No critical misconception around cloud service models, control/data planes, autoscaling, shared responsibility, quotas, zones/regions, serverless, or cloud-native

## Critical Misconceptions

A learner should not leave this topic believing that:

- cloud is only "someone else's server"
- control-plane health proves workload/data-plane health
- autoscaling automatically fixes performance
- managed services remove customer responsibility
- serverless means there are no servers
- public cloud means publicly reachable
- two zones automatically mean disaster recovery
- multi-cloud automatically improves resilience
- cloud capacity is unlimited
- cloud-native means Kubernetes
