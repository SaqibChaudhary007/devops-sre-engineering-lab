
# D00-T001 Assessment Package — How Computers Work

This package assesses whether the learner can move beyond definitions and reason about CPU, memory, storage, I/O, networking, processes, bottlenecks and resource behavior.

## Assessment Components

1. [Knowledge Check](knowledge-check.md)
2. [Applied Scenario](applied-scenario.md)
3. [Senior / SRE / Architect Follow-Ups](interview-followups.md)
4. [Teach-Back Assessment](teach-back.md)
5. [Rubric & Self-Review Guide](rubric.md)

## Recommended Order

Knowledge Check
→ Applied Scenario
→ Follow-Ups
→ Teach-Back
→ Rubric Review

## Pass Guidance

For topic-level competency:

- Knowledge Check: at least 80%
- Applied Scenario: at least 75%
- Follow-Ups: demonstrate at least L3 reasoning
- Teach-Back: at least 4/5 average
- No critical misconception about CPU, memory, storage, I/O or bottlenecks

## Critical Misconceptions

A learner should not leave this topic believing that:

- high CPU always means failure
- low free memory always means a memory problem
- free disk space proves storage health
- a network interface being UP proves application reachability
- low CPU proves the server is healthy
- the first symptom seen is automatically the root cause

## Evidence

This assessment package evaluates the mental models defined in D00-T001. It is not a certification exam and should not be treated as one.
