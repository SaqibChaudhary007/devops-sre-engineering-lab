# Labs

Labs are cross-topic practical assets.

## Types

- OBS — Observation
- EXP — Experiment
- LAB — Build
- BBF — Build-Break-Fix
- TS — Blind Troubleshooting
- INC — Incident Simulation
- ARCH — Architecture Exercise
- TEACH — Teach-Back
- CAP — Capstone

## Practical Rule

```text
Observe → Build → Validate → Break → Troubleshoot → Recover → Improve
```

A lab is marked **Lab Verified** only after its documented procedure has been executed successfully in the stated environment/version.

Failures should be introduced only in controlled lab environments.
