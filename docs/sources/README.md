# Sources & Evidence

Technical credibility depends on knowing where information came from and how strongly it has been validated.

## Source Hierarchy

1. Standards / specifications
2. Official documentation
3. Authoritative engineering publications
4. Reputable books, papers and technical references
5. Reproduced lab evidence
6. Sanitized production experience / interview reports
7. Community discussion

## Validation Status

DRAFT → RESEARCHED → DOC-VERIFIED → LAB-VERIFIED → PRODUCTION-OBSERVED / TECHNICALLY-REVIEWED

AI-generated material is always a draft until verified.

## Rule

Use the strongest source appropriate to the claim and clearly distinguish facts, recommendations, observations and opinions.
