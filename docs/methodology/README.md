# Learning Methodology

The platform is built around a progressive engineering model:

> **Learn → Build → Break → Troubleshoot → Interview → Architect → Teach**

## Learner Experience Standard

A learner should always know:

1. where they are
2. what prerequisites they need
3. what they will learn
4. why it matters
5. how to practice it
6. how it fails
7. how to troubleshoot it
8. how it appears in production
9. how to prove mastery
10. what to learn next

## Engineering Progression

```text
Definition
→ Mental Model
→ Architecture
→ Internals
→ Practical
→ Failure
→ Evidence
→ Troubleshooting
→ Reliability
→ Trade-Offs
→ Teach-Back
```

Professional depth should make learning clearer, not more confusing.
