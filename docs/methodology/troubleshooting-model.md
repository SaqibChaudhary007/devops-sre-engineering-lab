# Troubleshooting Model

## Standard Flow

```text
Symptom
→ Impact
→ Scope
→ Evidence
→ Recent Changes
→ Hypotheses
→ Test
→ Mitigation
→ Root Cause
→ Permanent Fix
→ Prevention
```

## Core Rule

> Do not start with commands. Start with the problem.

Good troubleshooting narrows scope, preserves evidence, tests hypotheses and distinguishes mitigation from permanent correction.

A successful command is not enough; recovery must be validated technically and from the user's perspective.
