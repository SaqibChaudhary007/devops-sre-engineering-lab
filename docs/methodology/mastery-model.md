# Mastery Model

The platform separates exposure, competency and mastery.

## Concept Levels

L1 Foundation → L2 Engineer → L3 Senior → L4 SRE → L5 Architect

## Practical Levels

P0 Theory → P1 Observe → P2 Build → P3 Break/Recover → P4 Blind Troubleshoot → P5 Design/Improve

## Interview Levels

IM-1 Recall → IM-2 Explain → IM-3 Apply → IM-4 Defend → IM-5 Lead

## Follow-Up Depth

FD-1 Root question → FD-5 Architecture/trade-off depth

## Mastery Dimensions

- concept
- connection
- practical
- troubleshooting
- reliability
- architecture
- communication

A single percentage must never hide a critical weakness.
