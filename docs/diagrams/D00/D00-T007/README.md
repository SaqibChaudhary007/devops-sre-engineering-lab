## Design Rules

- optimize the whole delivery system
- show feedback loops, not only forward flow
- separate tools from engineering outcomes
- use current five-metric DORA framing
- connect delivery speed to reliability and recovery
- keep Mermaid diagrams editable and reusable
- preserve the distinction between DevOps, SRE, and platform engineering

## Status

These diagrams support D00 mental models. Detailed CI/CD implementation, SRE operations, platform engineering, GitOps, observability, and security implementation belong to later domains.
