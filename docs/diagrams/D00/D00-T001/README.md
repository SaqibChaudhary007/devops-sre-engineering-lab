
# D00-T001 Visual / Diagram Package — How Computers Work

This package provides reusable diagrams for **00.01 — How Computers Work**.

The diagrams are intentionally simple at first and progressively connect foundational concepts to Senior, SRE and Architect thinking.

## Diagram Set

1. [DIA-D00-001 — Computer System Overview](DIA-D00-001-computer-system-overview.md)
2. [DIA-D00-002 — Memory & Storage Hierarchy](DIA-D00-002-memory-hierarchy.md)
3. [DIA-D00-003 — Application to Hardware Flow](DIA-D00-003-application-to-hardware-flow.md)
4. [DIA-D00-004 — Bottleneck & Queueing Mental Model](DIA-D00-004-bottleneck-queueing.md)
5. [DIA-D00-005 — Process & Resource Relationship](DIA-D00-005-process-resource-relationship.md)

## Design Rules

- diagrams explain one primary idea at a time
- beginner view appears before advanced interpretation
- labels use engineering terminology consistently
- diagrams remain readable directly in GitHub
- Mermaid source is version-controlled and editable
- diagrams can later be reused in videos, articles and slides

## Learning Progression

~~~text
Computer Components
        ↓
Memory Hierarchy
        ↓
Application → OS → Hardware
        ↓
Workload → Queue → Bottleneck
        ↓
Process → Resource Consumption
~~~

## Status

All diagrams are **conceptual learning diagrams**. They describe mental models rather than exact physical hardware implementation.
